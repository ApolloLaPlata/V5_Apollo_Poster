# V5 Apollo Poster (Capitania #13)

Central Onicanal de Despacho, Agendamento e Engajamento Automatizado da Holding V5 Apollo.

## Recursos
- **Master Calendar (30 Dias):** Planejamento visual de postagens com filtragem por canal e status.
- **Dual Beehiiv Publisher:** Criação simultânea de artigo para Blog e Newsletter HTML por e-mail.
- **Comment-to-DM Automation:** Resposta automática a comentários em posts sociais com envio de links e captação de leads (estilo ChatbotX).
- **Offer Group Dispatcher:** Disparo automatizado de promoções e cupons para grupos VIP no WhatsApp e Telegram (integração nativa com o V5 Finders).

## Execução
```bash
npm install
npm run dev # Roda na porta 3011
npm run build
```
